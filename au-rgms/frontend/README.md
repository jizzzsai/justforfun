# Frontend

This folder contains every browser-visible AU-RGMS page, reusable UI component, menu/status configuration, stylesheet, and researcher AI interface.

The university login screen is in `website-login-layout-and-navigation.jsx`. Its isolated desktop/mobile styles are in `login-page-design.css`; authentication and Remember me session handling are in `../database/login-and-database-connection.js`.

For feature-to-file mapping, see [`../documentation/PROJECT-FILE-GUIDE.md`](../documentation/PROJECT-FILE-GUIDE.md).
